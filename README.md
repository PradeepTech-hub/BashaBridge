# 🗣️📚 Bhasha Setu

**Bhasha Setu** is an Android application developed to help **government school students** improve their **English language skills** using **Kannada** as a bridge language.

The application focuses on **basic vocabulary, pronunciation, listening, speaking, and sentence formation**, aligned with the **Karnataka Government School 1st & 2nd Standard syllabus**.

---

## 🎯 Objective

Bhasha Setu aims to help young learners:

* 📖 Understand English through Kannada
* 🗣️ Improve pronunciation and speaking skills
* 💬 Build confidence in communication
* 🎓 Learn English in a simple, visual, and interactive way

---

# ✨ Features

## 📘 Standard-Based Learning

Students can learn based on their class level:

* 1st Standard
* 2nd Standard

Content is organized according to the Karnataka Government School syllabus to ensure age-appropriate learning.

---

## 🌐 Bilingual Learning Support

Languages Supported:

* 🇬🇧 English (Default)
* 🇮🇳 Kannada (Support Language)

Kannada explanations help students easily understand English words and sentences.

---

## 📂 Category-Based Learning

Learning content is divided into familiar categories:

* 🐶 Animals
* 🍎 Fruits
* 🏠 Daily Use Objects
* 🎒 School Objects
* 🔢 Numbers
* 🗣️ Simple Sentences

Each category contains **50+ words and sentences** suitable for beginner learners.

---

## 🎧 Interactive Learning System

Students can practice English through three simple steps:

### 🔊 Listen

* Hear the correct pronunciation using Android Text-to-Speech.

### 🎤 Speak

* Practice speaking using Android Speech Recognition.

### 📊 Get Instant Feedback

The application evaluates pronunciation and provides feedback such as:

* ✅ Excellent
* 👍 Very Good
* 🔁 Try Again

---

## 🧠 Pronunciation-Focused Learning

Designed specifically for **Kannada medium students**, the app helps learners:

* Improve pronunciation
* Learn correct English sound patterns
* Gain confidence in speaking English

---

## 📈 Progress Tracking

Student learning progress is stored locally using **SQLite**.

Features include:

* Score tracking
* Learning history
* Performance monitoring
* Improvement over time

---

## 🎨 Child-Friendly User Interface

The application is designed for young learners with:

* Large buttons
* Simple navigation
* Colorful visuals
* Clean Material Design interface
